# ZeroEB

Website for [ZeroEB](https://zeroeb.com), a residential rooftop solar installer based in Madipakkam, Chennai.

The live site is still on Hostinger. This project is set up to publish with **GitHub Pages** and use `zeroeb.com` as the custom domain.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Connect zeroeb.com on GitHub

The site already lives in [balachandarj-hash/ZeroEB](https://github.com/balachandarj-hash/ZeroEB) on the GitHub account [balachandarj-hash](https://github.com/balachandarj-hash). Sign into that account before pushing.

```bash
git remote add github https://github.com/balachandarj-hash/ZeroEB.git
```

The HTML source stays on `main` in that repository. The published site is the Next.js export on `gh-pages`, with Pages set to that branch and the custom domain `zeroeb.com`. Do not push this history onto `main`.

```bash
npm run build
```

Leave `PAGES_BASE_PATH` unset. `zeroeb.com` is served from the domain root, and `public/CNAME` contains `zeroeb.com`.

### DNS at Hostinger

Add the domain in GitHub Pages before changing DNS. In hPanel → DNS for `zeroeb.com`, remove the old Hostinger `A` or parking records for `@` and `www`, then add:

| Type | Name | Value |
| --- | --- | --- |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |
| CNAME | `www` | `balachandarj-hash.github.io` |

The `www` record points at `balachandarj-hash.github.io`, not at the repository name. GitHub will redirect `www.zeroeb.com` to `zeroeb.com`.

Until those records propagate, https://zeroeb.com keeps serving the Hostinger site.

- Home, about, services, Chennai installation, labour-only installation, panel cleaning, work gallery, contact, quote, videos, and blog
- Locality pages for the Chennai neighbourhoods on the current site
- Enquiry forms that email `ecopower2026@gmail.com`
